📝 Form Filler

// · turns a flat PDF or Word file into a fillable form · runs on this device · nothing uploaded
📄→✍️

Drop a .pdf or .docx here, or choose one.
Every blank line, box and tick square becomes typeable.

How it works. The file is read here, on your device — it is never sent anywhere. You get a preview with a box drawn on every blank it found, numbered in the order the Tab key will follow. Fix anything it got wrong, then save the fillable PDF.

Two columns. Where a page has two columns of blanks side by side, Tab runs all the way down the left column first, then all the way down the right one.

Labels with no line. A label ending in a colon with empty space after it — "Name :" in a table cell — gets a box too, even with no line drawn.

Scanned pages. A photo or scan has no text to read, so nothing is found automatically — you can still draw every field by hand.

Word files. Layout is re-created and comes out close, not identical. For an exact match, save the Word file as PDF first and feed it that.

No internet needed. Once this page has loaded once it keeps working with the network off. To carry it around as a single file, save the copy below and open it from your Downloads folder — it needs nothing else.

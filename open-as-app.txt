INSTALLING EACH TOOL AS ITS OWN APP

Each tool is now its own app, with its own icon and its own
window. About a minute each.

READ THIS FIRST — IT IS THE WHOLE REASON THIS DID NOT WORK
BEFORE: any Utilities icon already on your home screen has to be
removed before installing. The old one claimed the whole site, so
Chrome kept saying "you already have this app" instead of
offering to install a new one. Press and hold each old Utilities
icon, choose "Remove", and only then continue.


1. In Chrome (not from inside an installed app), open the tool
you want:

The converter:
https://moshgrossman.github.io/Utilities/converter/

Audio Finder:
https://moshgrossman.github.io/Utilities/audio-finder/

Form Filler:
https://moshgrossman.github.io/Utilities/form-filler/

Daycare Forms:
https://moshgrossman.github.io/Utilities/daycare-forms/

The all-in-one launcher, if you want it too:
https://moshgrossman.github.io/Utilities/home/


2. Tap Chrome's three-dot menu, then "Install app". On some
versions it says "Add to Home screen" — same thing.

If the menu does not offer it, you are probably looking at the
page inside an app window rather than in Chrome itself. Open the
address above in a normal Chrome tab and try again.


3. Tap "Install" (or "Add").


4. Check the home screen. You should see a separate icon: a
yellow page for the converter, teal headphones for Audio Finder,
the Form Filler icon, a yellow page with a teal tick for Daycare
Forms, a yellow U for the launcher. Tap it — that tool opens in its own
window, with its own entry in recent apps. In DeX it gets its own
desktop-style window.


5. Repeat from step 1 for the next tool.


DAYCARE FORMS AS AN APP: once installed, it works with no
internet at all, like the single-file copy. Its saved children
belong to the app (the same as the web address in Chrome), not
to the single file. If you have been using the single file, open
it, tap "Save backup", then open the app and tap "Load backup".


THE OLD ADDRESSES STILL WORK. If you have the previous links
saved anywhere, they now forward to the new ones automatically —
nothing you bookmarked is broken.
